# گیم‌کاد دیزاین — نسخه ۲

نسخهٔ فعلی سایت دیزاین (`gamekad-design`). نسخهٔ قبلی بدون الکترونیک و چینش خانه در پوشهٔ **`gamekad-design-v1`** نگه داشته شده.

جدید در v2:

- بازی‌های الکترونیک (فیفا، پلی‌استیشن، آرکید) + افزودن بازی از پنل
- چینش صفحهٔ اصلی شبیه المنتور: بکش، جابه‌جا کن، بخش را خاموش کن
- لیدربورد دوتایی ادمین (رکاد / خارج)، گرداندگی شب، نقش‌ها جدا به ازای سناریو
